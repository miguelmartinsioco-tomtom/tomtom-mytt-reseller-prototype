MyTomTom for Resellers

How a reseller onboards and provisions their own customers in MyTomTom. Target state, styled with Playbook and built on existing MyTomTom patterns. Reseller view only: end customers can't log in yet.

Flow A, new customer: Start onboarding with the account check set to No existing account (or Self-service account, which behaves the same for the reseller). Ends with the starter key.

Flow B, existing business account, confirmed: Start onboarding with Business account. Onboarding pauses; use the toolbar to simulate Confirmed, then continue.

Flow C, direct conflict: same as B, then simulate Conflict. The request closes and points to the account manager.
